자간 (letter-spacing) — 상황별

상황letter-spacing메모
큰 제목 (한글)-0.02em ~ -0.04em폰트 기본값에서 시작해 글자 사이가 넓어 보일 때 조금씩 좁히기.
큰 제목 (영문)-0.01em ~ -0.03em디스플레이 폰트일수록 좁히기.
본문0 ~ -0.01em거의 건드리지 않음. 폰트 기본값 신뢰.
대문자 영문 (라벨)+0.05em ~ +0.1em짧은 ALL CAPS 라벨은 자간을 조금 벌려 비교하기.
작은 글씨 / 캡션0 ~ +0.01em작을수록 살짝 벌리면 또렷.

핵심 직관: 글자가 커질수록 자간은 좁게(음수), 행간도 좁게. 작아질수록 반대. 한글은 영문보다 행간 +0.1, 자간은 글꼴의 기본 설계에 맞춰 조절.

폰트·언어에 따라 다름: 영문 디스플레이/제목은 자간을 살짝 넓혀(+) 시원하고 모던하게 가기도 합니다(특히 ALL CAPS·기하학 산세리프). 한글 큰 제목은 반대로 음수가 자연스러워요. 본문은 자간 0%에서 시작, 짧은 SNS 설명은 행간 140~160%, 긴 한글 웹 본문은 160~180%부터 비교해 보세요.

모바일에서 읽히는 SNS 디자인

투표 배너 · 이벤트 이미지 · 카드뉴스를 위한 1080×1080px 원본 기준 가이드. 아래 수치는 공식 플랫폼 규정이 아닌 권장 시작값이며, 글꼴과 실제 표시 크기에 따라 조절합니다.

본문 48~54px부터 시작하세요.

1080px 이미지가 화면에서 가로 360px로 표시되면 48px 글자는 약 16px 크기가 됩니다. 웹 본문의 16 CSS px를 이미지 원본에 그대로 적용하지 마세요.

01 · 글자 크기 — 모두 원본 px

용도권장 크기적용 예시
메인 타이틀80~110px투표명 · 이벤트명
소제목 · 핵심 메시지60~72px혜택 · 페이지별 제목
본문 설명48~54px참여 방법 · 콘텐츠 설명
기간 · 중요 조건48~54px마감 일시 · 참여 대상
짧은 인물명 · 라벨42~48px아이돌 이름 · 카테고리
보조 정보36~40px출처 · 간단한 부연에 제한적으로 사용

기간과 참여 조건은 필수 정보입니다. 하단에 있다는 이유로 줄이지 마세요. 36~40px은 읽지 않아도 핵심 내용을 이해할 수 있는 부연용이며, 같은 크기도 글꼴에 따라 다르게 보입니다.

02 · 모바일에서는 얼마나 작아질까?

1080px 원본 글자 크기가로 360px로 표시할 때
60px약 20px
48px약 16px
36px약 12px
30px약 10px

계산: 원본 글자 크기 × (화면에서 이미지가 표시되는 폭 ÷ 원본 이미지 폭). 휴대폰의 물리 픽셀 해상도가 아닌 실제 표시 폭 기준입니다. 앱의 여백이나 미리보기 방식에 따라 달라집니다.

03 · 글꼴 · 굵기 · 행간

항목추천 시작값
본문 굵기Regular~Medium
짧은 핵심 정보Medium~Semibold
타이틀 굵기Bold 이상에서 디자인에 맞게
여러 줄 본문 행간140~160%

예: 본문 48px → 행간 약 68~77px. 이 행간은 짧은 SNS 설명용 시작값입니다. 긴 웹 본문과는 별도로 조절하세요. 포토샵에서는 글자 크기 단위를 px로 확인하고, pt 숫자를 그대로 옮기지 마세요.

본문은 선명하게

획이 너무 가늘거나 폭이 지나치게 좁은 글꼴은 피하고, 한글 획과 속공간이 축소 후에도 구분되는지 확인합니다.

효과는 짧은 제목에

장식적인 글꼴 · 입체 효과 · 글로우는 짧은 제목에 집중하세요. 작은 안내문까지 적용하면 획 경계가 흐려질 수 있습니다.

04 · 여백과 정렬 — 1080px 원본 기준

위치권장 여백
이미지 바깥쪽과 주요 내용 사이64~80px
박스 테두리와 내부 글자 사이32~48px
제목과 관련 설명 사이24~40px
서로 다른 정보 묶음 사이48~72px

디자인 여백의 시작값이며 플랫폼별 잘림 방지를 보장하는 안전영역은 아닙니다. 짧은 제목은 가운데 정렬도 좋지만, 여러 줄 설명은 왼쪽 정렬로 시작하면 읽는 흐름을 잡기 쉽습니다. 관련 정보는 가깝게, 다른 내용은 더 멀리 배치하세요.

05 · 색과 배경 대비

본문 · 기간 · 조건은 4.5:1 이상

WCAG AA는 일반 텍스트에 4.5:1 이상, 큰 텍스트에 3:1 이상의 명도 대비를 제시하며 이미지 속 텍스트에도 적용합니다. 큰 글자의 기준은 원본 숫자가 아닌 실제 표시 크기로 판단합니다.

복잡한 배경과 글자를 분리

연한 배경 위 연한 글씨, 홀로그램 · 사진 위 작은 글씨, 과한 글로우를 주의하세요. 글자 뒤에 단색 면이나 어두운 그라데이션을 깔면 대비를 확보하기 좋습니다.

근거: W3C · WCAG 2.2 명도 대비 안내 ↗. 큰 텍스트의 기준은 약 24 CSS px 이상 또는 굵은 글자 약 18.7 CSS px 이상입니다.

06 · 정보가 넘치면 이 순서로 조정

읽는 순서를 제목 → 핵심 내용 → 기간 · 참여 방법으로 잡고, 크기 · 굵기 · 색에 차이를 줍니다.

  1. 중복 문장을 줄인다.
  2. 설명을 짧은 문장으로 나눈다.
  3. 다음 페이지나 게시글 본문으로 옮긴다.
  4. 마지막에 글자 크기를 소폭 조절한다.

07 · 내보내기 전 확인

33% 보기는 빠른 근사 확인입니다. 실제 휴대폰 확인을 함께 하세요. 체크 상태는 새로고침하면 초기화됩니다.
